# Manual de usuario

## 1. Importar archivos

- Haz clic en "Importar .md" para cargar uno o varios reportes.
- Haz clic en "Importar carpeta" para importar una estructura completa de Markdown.
- También puedes arrastrar archivos directamente a la zona de carga.

## 2. Revisar el contenido

- Selecciona un archivo en la lista de entradas.
- Usa la pestaña "Renderizado" para ver la vista previa estéticamente estructurada.
- Usa "Original" para ver el Markdown sin transformar.

## 3. Configurar la salida

- Elige entre convención individual, consolidada o por carpetas.
- Define el nombre del documento resultante.
- Activa la portada, TOC y saltos de página según corresponda.

## 4. Convertir

Pulsa "Convertir documentos". La aplicación envía el contenido al backend local, que genera los archivos DOCX en la carpeta de salida local.

## 5. Descarga

Una vez generado el resultado:

- descarga el archivo directamente desde el enlace
- o guárdalo en una carpeta local seleccionada con la opción "Guardar en carpeta"

## 6. Recomendaciones

- Mantén los Markdown en estructura clara con encabezados y listas.
- Para imágenes locales, usa rutas relativas dentro del mismo proyecto.
- Revisa el contenido antes de convertir documentos grandes o complejos.
